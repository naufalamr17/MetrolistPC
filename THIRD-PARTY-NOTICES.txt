FFMPEG DECODER
The initial Windows installer bundles an unmodified, separate FFmpeg executable:
7.1.1-essentials_build-www.gyan.dev, GPL version 3.
Copyright (c) 2000-2025 the FFmpeg developers.
Build distributor: https://www.gyan.dev/ffmpeg/builds/
FFmpeg source revision: https://github.com/FFmpeg/FFmpeg/commit/db69d06eee
Source archive: https://github.com/FFmpeg/FFmpeg/archive/db69d06eee.tar.gz
The build's original README lists configuration and external library versions.
The installer includes that file as FFmpeg-README.txt and the supplied GPL text
as FFmpeg-LICENSE.txt in the application resources. The FFmpeg executable runs
as a separate process; the desktop application does not link FFmpeg libraries.
The FFmpeg source archive alone is not the complete source for every external
library in this static build. Preserve the build configuration and obtain the
matching external library sources/build instructions before redistributing a
modified decoder or claiming a complete corresponding-source package.
